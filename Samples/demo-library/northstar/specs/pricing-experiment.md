# Pricing experiment — Northstar Analytics

Sample markdown for the library UI. All figures are made up.

## Hypothesis

A three-tier grid (**Starter / Pro / Team**) with annual toggle will lift paid conversion vs the current single “Talk to us” CTA.

## Variants

| Variant | Hero | Primary CTA |
|---------|------|-------------|
| A (control) | “Analytics for product teams” | Talk to sales |
| B | “Ship decisions, not dashboards” | Start free |
| C | Same as B + annual −20% | Start free |

## Success metrics

- Free → paid conversion (14d)
- Time on pricing page
- Support tickets mentioning “price”

## Guardrails

Do not change Enterprise SKU or contract language in this test.
