# Onboarding plan — Harbor Desk

> **Fictional sample** for Canvas Library screenshots. Not a real product.

## Goal

Get a new workspace from *invite accepted* → *first board shared* in under **8 minutes**.

## Funnel (demo numbers)

- **Invite open** — 12% drop · email client previews ok  
- **Account create** — 18% drop · SSO path is faster  
- **Sample board** — 9% drop · prefill “Team standup”  
- **First share** — 22% drop · hardest step today

## Principles

1. **One happy path** — SSO + sample board, no empty-state essay
2. **Show value before config** — templates before integrations
3. **Quiet chrome** — hide advanced settings until day 2
